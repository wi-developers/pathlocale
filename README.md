# pathlocale

A Nextcloud 34 app used by WI on <https://path.wi.sa> (Path | بث). It adds missing Arabic and English
texts, loads the IBM Plex Sans Arabic font, offers an Arabic/English switch on the login and public
pages, and replaces the upstream product name in interface texts. It changes no Nextcloud file.

- Licence: GNU AGPL v3 or later (`COPYING`). Credits and third-party notices: `NOTICE`.
- Source of the version running on path.wi.sa: this repository, tag `v0.1.2`. The deployable package
  contains only `appinfo/`, `lib/`, `css/`, `js/` and `fonts/`; everything else is tests, tools and
  the dictionary generator.
- Build the package: `sh tools/build-package.sh <commit> <outdir>` (deterministic; the 0.1.2 package
  has sha256 `ee0b9f817e957d7353b654af04cbe28be32f4e45adadadaed564f678a24ba194`).
- Dictionaries: `data/*.json` are generated by the scripts in `generator/` from Nextcloud's own
  translation files (they read an extracted copy of Nextcloud 34.0.5; paths are hard-coded for WI's
  workstation and must be adapted).
- Tests: `tools/run-tests.sh` (needs a Nextcloud test environment).
