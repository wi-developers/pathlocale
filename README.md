# pathlocale

A Nextcloud 34 app used by WI on <https://path.wi.sa> (Path | بث). It adds missing Arabic and English
texts, loads the IBM Plex Sans Arabic font, offers an Arabic/English switch on the login and public
pages, and replaces the upstream product name in interface texts. It changes no Nextcloud file.

- Licence: GNU AGPL v3 or later (`COPYING`). Credits and third-party notices: `NOTICE`.
- Source of the version running on path.wi.sa: this repository, tag `v0.1.4`. The deployable package
  contains only `appinfo/`, `lib/`, `css/`, `js/` and `fonts/`; everything else is tests, tools and
  the dictionary generator.
- Build the package: `sh tools/build-package.sh <commit> <outdir>` (deterministic; the 0.1.4 package
  built from commit `e37f8ac` has sha256 `8cd31455584ee1eeb4dcdabfc5a48372a9a5f6931b0e96b9067dcd7a7f409b7c`;
  the earlier 0.1.2 package has `ee0b9f817e957d7353b654af04cbe28be32f4e45adadadaed564f678a24ba194`).
- Dictionaries: `data/*.json` are generated by the scripts in `generator/` from Nextcloud's own
  translation files (they read an extracted copy of Nextcloud 34.0.5; paths are hard-coded for WI's
  workstation and must be adapted).
- Tests: `tools/run-tests.sh` (needs a Nextcloud test environment). `tools/mutate.mjs` plants 107 deliberate
  faults one at a time and checks that a test fails; `tools/mutation-results.json` holds the last run (105 caught;
  the 2 survivors, P07 and J18, are listed with reasons in `tools/equivalent-mutants.json`).
- Icons on the Talk home page are Material Design Icons paths (Apache-2.0, Pictogrammers); the licence text is
  `css/ICONS-LICENSE.txt`.
